# Data

`kidney_disease.csv`: the UCI Chronic Kidney Disease dataset, 400 patients (250 CKD, 150 not CKD), 24 features, converted from the original ARFF. Redistributed under CC BY 4.0.

Source: Rubini, L., Soundarapandian, P., & Eswaran, P. (2015). *Chronic Kidney Disease* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5G020

To rebuild it from the original source: delete the CSV and run `make data`.
